# 关屏时间切换

双击本目录的 `关屏时间切换.exe` 即可切换。需要桌面入口时，在 PowerShell 中运行本目录的 `Install.ps1`，然后双击桌面「关屏时间切换」。也可以右键程序，选择「显示更多选项 → 固定到任务栏」，之后单击任务栏图标即可使用。

![切换结果提示](preview.png)

- 当前为「从不」时，切为「1 分钟关屏」，同时记住原亮度并降至屏幕支持的最低档。
- 当前为「1 分钟」时，切为「从不关屏」，同时恢复之前保存的原亮度。
- 重复设为「1 分钟」不会覆盖最初保存的亮度；中途手动调亮后再次使用，也仍可恢复最初的亮度。
- 没有保存过原亮度时，切到「从不」会保留当前亮度。若你在设置中改成其他关屏时间，下次使用本工具会切为「从不」并尝试恢复已保存的亮度。
- 右下角显示结果约 3 秒；点击提示可提前关闭。提示期间重复启动会被忽略，避免连点来回切换。
- 关屏计时只修改**当前电源计划、接通电源时的自动关屏时间**；电池关屏、系统睡眠时间保持原样。亮度立即调整当前支持控制的屏幕，在电池供电时启动也会联动亮度。
- 部分屏幕驱动会同步更新插电与电池亮度档位（本机也是如此）；切回「从不」时恢复切换前的实际亮度。
- 最低亮度按屏幕实际支持档位确定；本机实测为 0%，这不等于关闭屏幕。
- 不支持此亮度接口的外接显示器会显示提示；关屏时间仍可正常切换。亮度调整失败时也会明确提示，失败提示停留约 7 秒。
- 每次启动都读取实际设置；更换电源计划后也可直接使用。
- 设置保存到 Windows，程序随后退出，不常驻、不联网、不需要开机启动。
- 「从不关屏」只关闭自动关屏计时，系统仍会按原来的睡眠时间休眠；程序也不会改变锁屏策略。

## 其他用法

程序支持下列参数，可在 PowerShell 中使用：

```powershell
& '.\关屏时间切换.exe' --status  # 查看关屏时间和当前亮度，12 秒后关闭
& '.\关屏时间切换.exe' --minute  # 1 分钟关屏 + 最低亮度
& '.\关屏时间切换.exe' --never   # 从不关屏 + 恢复原亮度
```

可附加 `--quiet` 禁用提示（用于脚本）。`last-state.json` 保存上次的关屏状态、亮度操作结果和警告；关屏单位为秒，0 代表从不。程序退出码为 0 表示成功，1 表示关屏操作失败，2 表示参数无效，3 表示关屏操作已完成但亮度联动未完成。`--status` 为只读操作，不修改或恢复亮度。

`brightness-backup.xml` 保存各屏幕切换前的亮度，成功恢复后自动清理。请勿在最低亮度模式下删除此文件；移动程序时请一并保留。屏幕暂时断开时保留其恢复记录，重新连接后再次切到「从不」即可恢复。上述运行记录不上传 Git。

`Verify.ps1` 会在真实屏幕上验证最低亮度、恢复、重复操作和错误处理，并在结束时还原测试前的设置；运行期间屏幕会短暂变暗。若有待恢复记录，先用工具切回「从不」再测试。

桌面快捷方式指向本文件夹，请保留本文件夹位置。若需移动，请更新快捷方式目标和图标。删除桌面快捷方式和本文件夹即可移除工具；移除不会更改已经设置的关屏时间。

源代码为 `ScreenTimeoutToggle.cs`，运行 `Build.ps1` 可用 Windows 自带 .NET Framework 编译器重新构建，不需要安装第三方依赖。

使用微软 Windows 电源管理 API 读取/写入交流电关屏时间，并重新应用当前计划使设置生效：
https://learn.microsoft.com/windows/win32/api/powersetting/nf-powersetting-powerwriteacvalueindex

亮度使用 Windows WMI 的 `WmiMonitorBrightness` / `WmiSetBrightness`，读取屏幕支持的实际档位并校验设置结果：
https://learn.microsoft.com/windows/win32/wmicoreprov/wmisetbrightness-method-in-class-wmimonitorbrightnessmethods
