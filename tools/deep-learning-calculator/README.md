# 深度学习尺寸计算器 · 卷积尺寸实验室

双击 `index.html`，用浏览器打开即可使用。无需安装依赖，可离线运行。

- **卷积**：根据输入尺寸、卷积核、步长、填充及膨胀计算输出尺寸。
- **转置卷积**：支持输出填充参数。
- **池化**：支持向下取整与向上取整模式。
- **感受野**：按层计算感受野与跳跃距离。
- **目标反推**：指定输出尺寸，反推步长或填充；向上取整模式暂不支持反推。
- 支持分别设置高度/宽度，也可联动输入尺寸和卷积核宽高。

本工具从 `AllPass001/convolution-shape-calculator` 迁入，功能文件保持原样，原始提交历史见 [Git 历史归档](../../history/)。后续在本仓库统一维护。
